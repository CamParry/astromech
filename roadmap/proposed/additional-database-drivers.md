# Additional Database Drivers

D1 was split out of this file on 2026-07-29 when it was built: see
`completed/d1-driver.md`.

Discussed 2026-10-03. **Still open: whether to support Postgres at all**, or
stay SQLite-only (libSQL and D1). The decisions below say how Postgres would
arrive if it does.

## What exists

- `SqlDialect` has one value, `'sqlite'`, and `columnType` switches over it
  exhaustively (`packages/astromech/src/database/table-snapshot.ts`), so adding
  `'postgres'` turns each place that needs handling into a type error.
- Every migration journal, the site's and each plugin's
  (`packages/plugins/redirects/migrations/0000_baseline.ts`), is raw SQLite DDL
  with backtick quoting.
- Other raw SQLite (`json_extract`, `PRAGMA`, `sqlite_master`) is 12 uses across
  `database/migrations.ts`, `drivers/libsql.ts`, `drivers/d1-introspector.ts`
  and `transport/cli/commands/plugin-purge.ts`.
- `DECISIONS.md` already names a `tsvector` index for search on Postgres, and the
  setup gate and the planned partial unique indexes work there.

## Prior art

- **Payload** ships one adapter package per database (`db-postgres`,
  `db-sqlite`, `db-mongodb`, `db-d1-sqlite`); each generates migrations from the
  config, and plugins ship none.
- **Strapi** and **Directus** use Knex and sync the schema from definitions.
- **Craft** supports MySQL and Postgres. **Ghost** narrowed to MySQL in
  production; **WordPress** is MySQL only.

## Decided, if Postgres comes

- **Postgres only, no MySQL.** MySQL has no partial indexes, which the
  `stagedFor` and field uniqueness indexes need, nor `RETURNING` or
  transactional DDL.
- **No preparation work now.** The trigger is a site that needs a host SQLite
  cannot serve (Neon, Supabase, Hyperdrive).
- **A core subpath**, `astromech/database/postgres`, on Kysely's
  `PostgresDialect` with `pg` as an optional peer dependency, like `libsql` and
  `d1`.
- **A plugin ships one journal per dialect it supports**, generated by
  `plugin:generate --dialect`. A plugin without a Postgres journal fails at boot
  on Postgres with a clear error. Rejected: Payload's model of generating plugin
  SQL in the site, which undoes self-contained plugin journals.
- **A site never switches dialect in place.** `db:generate` writes for the
  configured dialect; moving from SQLite to Postgres is a backups export and
  restore.

## Open
