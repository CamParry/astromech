# Drift is reported, not enforced

`pnpm run report:drift` (`scripts/report-drift.ts`) finds a second copy of a helper, a cast or a query key, and review decides whether to share it, schedule it or keep it.

**Rejected:** lint bans on code shapes and a count that may only fall (force awkward structure, as dependency-cruiser did); periodic clean-up passes (the drift returns).
